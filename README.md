# テニス乱数表 Webアプリ（PWA）

テニスコート1面で4〜8人のメンバーが継続的にダブルスを行う際、過去の確定履歴を考慮してペアや対戦相手の重複を避けた最適な組み合わせを生成するスマートフォン専用のWebアプリケーションです。

Progressive Web App (PWA) に対応しており、一度アクセスすればオフライン環境（テニスコート上など）でも快適に利用可能です。

---

## 🌟 主な機能

### 1. 参加人数の柔軟な設定
- **4〜8人の参加者に対応**: 参加者の表記は `1` 〜 `N` のシンプルで直感的な番号表示です。
- **自動休憩人数計算**: 休憩者数は常に `参加人数 - 4人` となります。

### 2. 休憩者の手動指定・自動ランダム決定
- **手動指定**: 各ゲーム開始前に、急な休憩や体調に合わせた特定のプレイヤーを手動で休憩指定できます。
- **自動ランダム決定**: 手動選択しなかった場合や不足人数がある場合は、アプリが自動でランダムに休憩者を選出します（ confirmation 画面で手動/自動の内訳を表示）。

### 3. 公平性評価アルゴリズムに基づく組み合わせ自動生成
過去の確定履歴から以下の優先順位でペナルティスコアを計算し、重複を極力避ける最良のペア・対戦カードを提案します。
1. ペア重複の回避（100pt/回）
2. 対戦相手重複の回避（10pt/回）
3. 同一対戦カードの回避（30pt/回）
4. 直前ゲームのペア回避（300pt/回）・直前ゲーム対戦カード回避（500pt）
5. 再抽選で直前表示と同一カードの回避（200pt）

### 4. 再抽選 & 出場者の手動位置入れ替え
- **再抽選**: 休憩者は変更せず、出場する4人のペア構成のみを公平に再生成できます。
- **手動位置入れ替え**: コート上のプレイヤー番号を2人タップするだけで、位置を自由に入れ替えられます。

### 5. 履歴管理・直前取り消し・個人統計
- **ゲーム確定と保存**: 確定したゲームは `localStorage` に即時保存され、ブラウザを閉じても維持されます。
- **直前の確定取り消し**: 誤って確定した場合でも、最新1ゲームの確定を取り消して状態を巻き戻すことができます。
- **参加状況統計**: メンバーごとの累計「出場回数」「休憩回数」をリアルタイムで確認できます。

### 6. PWA & オフライン対応
- **ホーム画面へ追加**: スマートフォンのブラウザからアプリとしてインストール可能です。
- **オフライン動作**: 初回アクセス後はネット接続なしでも全機能が動作します。

## 🚀 使い方・開発コマンド

### 動作要件
- Node.js (v18 以上推奨)
- npm

### セットアップ

```bash
# リポジトリのクローン・移動後、依存パッケージをインストール
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

起動後、ターミナルに表示されるローカルURL（例: `http://localhost:5173`）にアクセスしてください。

### プロダクションビルド & PWA生成

```bash
npm run build
```

`dist/` ディレクトリに最適化された静的ファイルおよび PWA サービスワーカーが生成されます。

### ビルド成果物のローカル確認

```bash
npm run preview
```

## 📱 画面フロー

1. **開始画面**: 参加人数 (4〜8人) を選択して開始。
2. **休憩者選択画面**: 休憩させたい人を選択（空欄の場合は「組み合わせを作成」時に自動決定）。
3. **組み合わせ確認画面**: コートレイアウトで対戦カードを確認。タップで選手入れ替えや「再抽選」を実行後、「確定」を押す。
4. **履歴・参加状況画面**: 過去の対戦履歴と各員の出場・休憩回数を確認。直前取り消しやデータリセットが可能。
