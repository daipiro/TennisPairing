# テニス乱数表 Webアプリ（PWA）

テニスコート1面で4〜8人のメンバーが継続的にダブルスを行う際、過去の確定履歴を考慮してペアや対戦相手の重複を避けた最適な組み合わせを生成するスマートフォン専用のWebアプリケーションです。

Progressive Web App (PWA) に対応しており、一度アクセスすればオフライン環境（テニスコート上など）でも快適に利用可能です。

---

## 🌟 主な機能

### 1. 参加人数の柔軟な設定
- **4〜8人の参加者に対応**: 参加者の表記は `1` 〜 `N` のシンプルで直感的な番号表示です。
- **自動休憩人数計算**: 休憩者数は常に `参加人数 - 4人` となります。

### 2. 直前ゲーム休憩者の優先出場アルゴリズム
- **連休防止・優先出場**: 直前ゲームで休憩していたメンバーは、次のゲームで優先的に出場（プレイ）させるようアルゴリズムを改良しました。

### 3. 再抽選時の休憩者含む全体再選出
- **手動固定以外の再選出**: 「組み合わせを再抽選」を押した際、手動固定指定されている休憩者以外を対象として、**休憩者の自動選出も含めて全体を再抽選**します。

### 4. 横一列レイアウトでの対戦組み合わせ表示
- **シンプルでクリーンな表示**: `[ 1 ] [ 2 ] VS [ 3 ] [ 4 ]` のように4人の出場プレイヤーが横一列に並びます。
- **直感的なタップ交代**: 出場者・休憩者を問わず、2つのボタンをタップするだけで自由に入れ替えや交代が可能です。

### 5. メイン画面内へのインライン休憩者選択（別画面への遷移不要）
- **対戦組み合わせの上に配置**: 休憩を手動固定したいプレイヤーの選択ボタン（1〜N）が「ゲームの組み合わせ」のすぐ上にインライン配置されています。
- **ワンタップ即時保持**: タップで固定指定のトグル切り替えができ、即座に組み合わせに反映・保持されます。

### 6. シームレスなメイン1画面操作 & リアルタイム時系列対戦履歴
- **メイン画面上部への時系列履歴表示**: 上部に過去の対戦履歴（第1ゲームが一番上、下へ追加）がリアルタイム表示されます。
- **直前確定取り消しボタン**: メイン画面下部からワンタップで直前1ゲームの確定を取り消して巻き戻せます（確認ダイアログなし）。

### 7. 履歴管理・直前取り消し・個人統計
- **ゲーム確定と保存**: 確定したゲームは `localStorage` に即時保存され、ブラウザを閉じても維持されます。
- **直前の確定取り消し**: 誤って確定した場合でも、最新1ゲームの確定を取り消して状態を巻き戻すことができます。
- **参加状況統計**: メンバーごとの累計「出場回数」「休憩回数」をリアルタイムで確認できます。

### 8. PWA & オフライン対応
- **ホーム画面へ追加**: スマートフォンのブラウザからアプリとしてインストール可能です。
- **オフライン動作**: 初回アクセス後はネット接続なしでも全機能が動作します。

## 🚀 使い方・開発コマンド

### 動作要件
- Node.js (v18 以上推奨)
- npm

### セットアップ

```bash
# リポジトリのクローン・移動後、依存パッケージをインストール
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

起動後、ターミナルに表示されるローカルURL（例: `http://localhost:5173`）にアクセスしてください。

### プロダクションビルド & PWA生成

```bash
npm run build
```

`dist/` ディレクトリに最適化された静的ファイルおよび PWA サービスワーカーが生成されます。

### ビルド成果物のローカル確認

```bash
npm run preview
```

## 📱 画面フロー

1. **開始画面**: 参加人数 (4〜8人) を選択して開始。
2. **メイン画面（1画面完結型）**:
   - **最上部**: これまでの対戦履歴（第1ゲームが一番上、下へ追加）。
   - **中央上部**: 休憩者の手動選択ボタン群（インライン配置）。
   - **中央下部**: 第 N ゲームの対戦組み合わせ（横一列表示）。タップで2人交代が可能。
   - **最下部**: アイコンのみの横並びアクションボタン (取り消し → 再抽選 → 確定)。
3. **履歴・参加状況詳細画面**: 累計の出場・休憩回数、データリセット。
